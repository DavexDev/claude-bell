# 🔔 claude-bell

Sound notifications for [Claude Code](https://claude.com/claude-code). Play a sound when:

- ✅ a task **finishes** (Claude stops responding)
- ⏳ Claude is **waiting for your approval** to run a tool
- 💤 Claude is **idle**, waiting for your next prompt
- 🤖 a **subagent finishes**

No more staring at the terminal waiting for Claude to need you. It works by
registering [Claude Code hooks](https://code.claude.com/docs/en/hooks-guide)
that run a tiny, dependency-free Node script to play a sound.

Cross-platform: **Windows, macOS, Linux**.

---

## Install

```bash
# Try it without installing:
npx claude-bell install

# Or install globally:
npm install -g claude-bell
claude-bell install
```

`install` adds the hooks to your **user** settings (`~/.claude/settings.json`),
so every Claude Code session notifies you. A timestamped backup of your settings
is written first, and only claude-bell's own entries are added — nothing else is
touched.

Then **start a new Claude Code session** so the hooks load.

> Prefer to enable it only for one project? Run `claude-bell install --project`
> to write to `.claude/settings.json` in the current directory instead.

## Test your audio

```bash
claude-bell test            # plays the "task complete" sound
claude-bell test waiting    # plays the "waiting for approval" sound
claude-bell test idle
claude-bell test subagent
```

## Uninstall

```bash
claude-bell uninstall            # from user settings
claude-bell uninstall --project  # from project settings
```

Removes only claude-bell's hooks (identified by the script path); the rest of
your `settings.json` is left intact.

## Customize

Create and edit your config:

```bash
claude-bell config
```

This creates `~/.claude/claude-bell.config.json` from the defaults:

```json
{
  "enabled": true,
  "sounds": {
    "complete": "complete.wav",
    "waiting": "waiting.wav",
    "idle": "idle.wav",
    "subagent": "subagent.wav"
  },
  "events": {
    "Stop": "complete",
    "Notification.permission_prompt": "waiting",
    "Notification.idle_prompt": "idle",
    "Notification.agent_completed": "complete",
    "SubagentStop": "subagent"
  }
}
```

- **Use your own sounds:** point a `sounds` entry at an absolute path to your own
  `.wav` file, e.g. `"complete": "C:/sounds/tada.wav"` or `"/home/me/ding.wav"`.
- **Remap events:** change which sound an event plays, or delete an `events` key
  to silence that situation.
- **Mute everything:** set `"enabled": false`.

Your config is merged over the defaults, so you only need to include the keys you
want to change.

### Event keys

| Key | Fires when |
|-----|------------|
| `Stop` | Claude finishes responding (task done) |
| `Notification.permission_prompt` | Claude asks to run a tool and needs approval |
| `Notification.idle_prompt` | Claude is idle, waiting for your next prompt |
| `Notification.agent_completed` | A background session finished or failed |
| `SubagentStop` | A subagent (Task) finished |

`play.js` reads the hook's `notification_type` from stdin to pick the right key,
falling back to a bare `Notification` key if you define one.

## How it works

`claude-bell install` writes hook entries like this into your `settings.json`:

```json
{
  "hooks": {
    "Stop": [
      { "matcher": "", "hooks": [
        { "type": "command", "command": "\"node\" \".../src/play.js\" Stop" }
      ] }
    ]
  }
}
```

On each event, Claude Code runs `play.js`, which reads the event JSON on stdin,
looks up the mapped sound in your config, and plays it using the OS-native
player:

- **Windows** — PowerShell `System.Media.SoundPlayer`
- **macOS** — `afplay`
- **Linux** — the first available of `paplay`, `aplay`, `ffplay`, `play`

Playback is fire-and-forget and errors are swallowed, so the notifier can never
break or slow down Claude Code.

## Limitations

- **No generic "error" sound.** Claude Code doesn't expose a dedicated hook for
  in-line errors or interruptions. The closest signal is
  `Notification.agent_completed`, which fires when a *background* session finishes
  **or fails** — you can map it to a distinct sound if you like.
- **Volume isn't adjustable** on Windows (`SoundPlayer` has no volume control).
  Use quieter source files if needed.
- Linux requires one of the players above to be installed
  (`pulseaudio-utils`, `alsa-utils`, `ffmpeg`, or `sox`).

## Development

```bash
git clone <repo>
cd claude-bell
npm link              # exposes the `claude-bell` command locally
npm test              # smoke tests (no audio, no settings changes)
npm run gen-sounds    # regenerate the bundled WAV files
```

The bundled sounds are synthesized tones generated by `scripts/gen-sounds.js`
(royalty-free, no third-party audio).
